# Looks: colour in one click

**Looks** on the rail holds 26 colour looks. Each one says in one line what it is for ("Neutral; calms reds so a face
reads even: talking head"), carries genre tags, and has one **Intensity** knob.

1. Select the clips on the timeline.
2. Open **Looks**. Narrow the list with the search box or a tag (*talking-head*, *travel*, *food*, *product-ad*,
   *tutorial*, *news*, *daily*, *cinematic*, *shorts*, *mono*, *fix*…).
3. The small pictures show each look on a sample scene. Tick **Preview on current frame** to see them on your own
   frame at the playhead instead (**Refresh** after moving the playhead).
4. Set **Intensity** (100 % = the look as designed; less is gentler). Each look has a safe range, so it never goes
   further than is good for skin and highlights.
5. **Apply**. The card says **Applied**.

Applying another look **replaces** the first one (looks never pile up). **Remove look** takes it off the selected
clips. **Cmd+Z** undoes either. ☆ marks a favourite: favourites stay at the top.

The look is an ordinary **Lumetri Color** effect on the clip, so you can fine-tune it in **Effect Controls** like any
grade. Looks are also in the command palette (type the look's name).

**Fix looks** (*Fix Orange Indoor Light*, *Fix Grey Day*) correct common problems rather than add a style; use them
first, then a style look if you want one.

Every look is checked: on reference colours it must not clip highlights, crush shadows or shift skin tones, at its
lowest, normal and highest intensity.
